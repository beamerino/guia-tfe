# Plantillas

Plantillas listas para usar, con la [estructura universal](estructura.md) y con indicaciones dentro de cada capítulo. No están ligadas a ninguna universidad: **adapta la portada y el formato a la normativa de tu centro**.

??? tip "Cómo usar la plantilla LaTeX en Overleaf"
    1. Entra en [Overleaf](https://www.overleaf.com/) con tu cuenta (muchas universidades ofrecen cuenta institucional).
    2. *New Project* → *Upload Project* y sube el `.zip` **sin descomprimir**.
    3. Compila. El archivo principal es `main.tex` y los capítulos están en la carpeta `capitulos/`.
    4. Para la bibliografía, exporta tu colección de Zotero con [Better BibTeX](bibliografia.md#zotero-en-10-minutos) y sustituye `referencias.bib`.

??? tip "Cómo usar la plantilla Word"
    1. Escribe encima de los textos de indicación (en gris) y bórralos al terminar.
    2. Usa los estilos **Título 1, 2 y 3** para los apartados: así el índice se actualiza solo (clic derecho en el índice → *Actualizar campos*).
    3. Inserta las citas con el complemento de [Zotero o Mendeley](bibliografia.md), nunca a mano.
    4. Inserta los pies con *Referencias → Insertar título*, para que figuras y tablas se numeren solas.
