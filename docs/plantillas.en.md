# Templates

Ready-to-use templates with the [universal structure](estructura.md) and guidance inside each chapter. They aren't tied to any university: **adapt the cover page and format to your institution's regulations**.

??? tip "Using the LaTeX template in Overleaf"
    1. Sign in to [Overleaf](https://www.overleaf.com/) (many universities provide an institutional account).
    2. *New Project* → *Upload Project* and upload the `.zip` **without unzipping it**.
    3. Compile. The main file is `main.tex` and the chapters are in the `chapters/` folder.
    4. For the bibliography, export your Zotero collection with [Better BibTeX](bibliografia.md#zotero-in-10-minutes) and replace `references.bib`.

??? tip "Using the Word template"
    1. Type over the guidance text (in grey) and delete it when you're done.
    2. Use the **Heading 1, 2 and 3** styles for sections, so the table of contents updates itself (right-click it → *Update Field*).
    3. Insert citations with the [Zotero or Mendeley](bibliografia.md) plugin, never by hand.
    4. Insert captions with *References → Insert Caption*, so figures and tables are numbered automatically.
